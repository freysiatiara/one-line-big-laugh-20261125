## The line

> I proved I'm human by failing the CAPTCHA three times. The robot passed on the first try.

89 characters. Two beats: a human fails the test designed to catch robots, then the robot passes it on the first try.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `ENTRY_OUTPUT`, or
`OUTPUT_DIR`/`MAKEFUN_OUTPUT_DIR` + `entry.txt`), stdlib only.
